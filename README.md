# Flavor Factory Site

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Unzip this project.
2. Push the folder to a new GitHub repo.
3. In Vercel, click **Add New > Project**.
4. Import the GitHub repo.
5. Accept the default Next.js settings.
6. Click **Deploy**.
